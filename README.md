# Cindy-ELYGPUI

Cindy's desktop client, ported to Rust on [GPUI](https://www.gpui.rs) and
[Ely GPUI Components](https://github.com/ELY-Open-Source/Ely-GPUI-Components).

Status: chapter 1 of 23. `docs/PRD.md` sets the scope; `TASKS.md` tracks progress.

## Build

```sh
cargo run
```

Rust 1.98. Linux, macOS and Windows, x86_64 and arm64.
